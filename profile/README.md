# Termnex

Control-panel wiring components, dimensional reference charts, and selection tools for industrial panel builders, electrical contractors, and OEM engineering teams.

🌐 **Website:** [termnex.com](https://termnex.com/) · 📩 **Enquiries:** `info@termnex.com`

---

## Open Reference Data on GitHub

- **[`panel-wiring-reference`](https://github.com/termnex-electrical/panel-wiring-reference)** — Machine-readable CSV and JSON reference tables for:
  - Wire ferrule collar colour codes (`0.5–50 mm²`) across **DIN 46228-4**, **French (NF C 63-023)**, and **Special ("German")** sequences
  - **772 OEM-to-Termnex wire ferrule cross-references** across 10 manufacturers (Phoenix Contact, Weidmüller, Panduit, WAGO, TE Connectivity, Schneider Electric, etc.)
  - **Metric (`M12–M63`) & PG (`PG7–PG48`)** nylon cable gland cable OD clamping ranges

## Free Interactive Tools & Engineering Guides

- **[Wire Ferrule Cross-Reference Finder](https://termnex.com/wire-ferrule-cross-reference/)** — Search single OEM part numbers or convert an Excel BOM
- **[Wire Ferrule Size & Colour Chart](https://termnex.com/wire-ferrule-size-chart/)** — Full `0.14–150 mm²` barrel dimensions and `mm² ↔ AWG` lookup
- **[Cable Gland Selector](https://termnex.com/cable-gland-selector/)** — Filter Nylon, Brass, and Multi-Hole glands by cable OD, thread, and panel wall thickness
- **[UL 486F vs CE & DIN 46228 Guide](https://termnex.com/blogs/wire-ferrule-ul-vs-ce/)** — Export panel compliance rules for EU and North American builds
- **[Resource Center](https://termnex.com/resource-center/)** — Printable checklists, thread charts, and product catalogues (no registration required)
